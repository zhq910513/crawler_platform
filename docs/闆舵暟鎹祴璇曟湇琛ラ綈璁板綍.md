# 零数据测试服补齐记录

本轮按“测试服完全零数据开始”的标准补齐以下内容：

## 新增脚本

- `deploy/scripts/reset-test-server.sh`：零数据重置安装脚本，清空测试服本地数据、生成 `.env` 强密码、构建服务、初始化空库并启动平台。
- `deploy/scripts/smoke-test.py`：端到端 smoke-test，使用标准 API 创建公司、Agent、待接入项目、正式项目、任务和运行实例；可启动真实 Agent 并等待任务容器执行成功。
- `deploy/scripts/smoke-test.sh`：Python smoke-test 的 Bash 入口。
- `deploy/scripts/test-server-validate.sh`：测试服一键验收入口，默认执行 Fresh Install + 真实 Agent + 真实任务容器链路。

## 新增测试爬虫项目模板

- `examples/smoke_spider/Dockerfile`
- `examples/smoke_spider/sch.py`
- `examples/smoke_spider/spiders/smoke_tasks.py`

该模板用于测试服构建本地 smoke 爬虫镜像，并验证：

- `sch.py` 静态 `TASKS` 解析。
- 项目镜像 digest 上报。
- Agent 按 digest 拉取镜像。
- 共享项目缓存目录 `/cache`。
- 独立运行目录 `/work`。
- 独立日志目录 `/logs`。
- 独立浏览器 Profile 目录 `/profiles`。
- `crawler_runtime` 入口执行。
