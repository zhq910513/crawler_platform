# 远程部署运行期目录过滤 v1.0.105

## 背景
测试服工作区会由 Docker Compose、MySQL、Redis、构建中心生成 `data/` 目录。`data/` 属于运行期持久化目录，不属于源码发布事实。

v1.0.104 已尝试通过 `.git/info/exclude` 忽略这些目录，但如果远程测试服之前已经存在旧 marker 且内容不完整，脚本会看到 marker 后直接跳过，导致 `?? data/` 仍然阻断部署。

## 方案
- 每次部署前重写 `# crawler_platform runtime excludes` 标记块，确保 `/data/` 等运行期路径一定存在。
- 在脏工作区判断前增加状态过滤，即使 exclude 文件历史上写坏，也不会把运行期目录当作真实代码改动。
- 保留真实改动阻断策略，避免自动部署覆盖人工代码修改。
