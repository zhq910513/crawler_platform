# CI 版本契约残留修复 v1.0.99

## 背景

v1.0.98 的商业发布门禁失败在后端回归测试阶段。失败原因不是构建中心主逻辑，而是 `backend/tests/test_rebuild_contract.py` 内部仍硬编码断言 `release_version == '1.0.97'`。

仓库根目录 `VERSION` 已提升到 `1.0.98` 后，该断言与真实发布版本冲突，导致 CI 失败。

## 修复

将测试断言改为读取当前仓库 `VERSION` 文件并进行一致性校验，避免未来 `1.0.x` 继续升级时再次遗留旧版本硬编码。

## 非目标

本次不调整构建中心流程，不修改数据库迁移，不改变 Agent 安装脚本的业务行为。
