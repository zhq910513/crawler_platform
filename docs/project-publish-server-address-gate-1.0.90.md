# 项目发布执行节点地址门禁 v1.0.90

## 背景

现场发现项目发布页显示：

```text
百度备用机 节点地址采集中 可部署
```

该展示会让用户误判节点已经满足部署条件。

## 处理

v1.0.90 将“节点地址采集中”纳入部署节点可用性门禁。

节点必须至少具备以下任一地址信息：

```text
serverIp
metrics.reportedAddress
metrics.hostIp
metrics.publicIp
metrics.hostname
```

否则即使 Agent 已经在线，项目发布页和后端发布流水线也会返回：

```text
节点地址采集中
```

## 不改变的契约

- 不修改 Agent 心跳协议字段。
- 不修改数据库结构。
- 不把平台构建中心能力伪装为已完成。
- 不修改爬虫项目。
