# 项目构建源码获取韧性 v1.0.102

v1.0.102 把源码获取从单一路径扩展为多级兜底：

1. `CRAWLER_PROJECT_SOURCE_MIRROR_MAP` 配置的镜像仓库。
2. 原始 Git 仓库 `git clone`。
3. GitHub 官方 codeload/archive 源码归档包。
4. 用户通过发布页上传的源码包。
5. 最近一次成功获取的源码缓存。

源码包上传接口按公司权限校验，只保存到平台构建目录下按仓库/ref 哈希隔离的目录，不会写入业务仓库，也不会修改已登记 Release。

最近成功源码缓存只作为最后兜底路径。使用该路径时，构建日志会标出 `SOURCE_CACHE` 并提示可能不是远端最新提交。
