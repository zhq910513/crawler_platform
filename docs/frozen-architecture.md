# 冻结架构说明

## 平台边界

- 前端：中文管理、配置、观察、人工确认。
- 后端：权限、状态机、调度、审计、告警、唯一事实来源。
- Agent：资源上报、镜像 digest 校验、容器执行、租约心跳、结果回传。
- 爬虫项目：业务代码、任务声明、镜像制品。

## sch.py 定位

`sch.py` 只用于本地执行和任务列表声明。上线后平台只接收 CI/CD 或隔离解析流程生成的 manifest，不把 `sch.py` 作为生产运行入口，也不使用其中的 Cron 作为生产调度。

## 状态机

执行节点状态拆为管理状态、连接状态、健康状态、负载状态；项目节点关系拆为部署状态、计划状态、镜像就绪状态；运行实例拆为执行状态和分配状态。

## 执行节点范围

项目支持多执行节点运行范围。主备模式需要一个主节点和多个备用节点；负载均衡模式可配置多个活动节点。多执行节点运行范围不等于把同一个任务重复发送到所有节点，任务多机并行必须走任务层分片能力。

## 告警通知

预留飞书、企业微信、钉钉、邮箱配置；初版只有 P0 外部通知，P1/P2/P3 只作为事件记录与页面展示预留。
