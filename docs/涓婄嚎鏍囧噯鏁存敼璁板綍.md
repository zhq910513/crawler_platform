# 上线标准整改记录

本轮按“测试服务器上线验收”口径继续整改，不以本地联调口径判断完成度。

## 已完成整改

1. 项目模板 `deploy/templates/project/bootstrap.sh` 改为 AST 静态解析 `sch.py` 中的 `TASKS`，不再 import 或执行 `sch.py`。
2. 真实 Agent 增加 `AGENT_CAPABILITIES_JSON`，心跳上报能力标签，支持后端 `requiredCapabilities` 路由匹配。
3. 项目模板增加 `runtime/` 与 `Dockerfile.example`，明确业务镜像必须安装 `crawler-runtime`。
4. GitHub Actions / GitLab CI 示例补充 `PROJECT_KEY / PROJECT_CODE / PROJECT_NAME / RELEASE_CHANNEL` 等变量要求。
5. 前端增加 `package-lock.json`，Dockerfile 改为 `npm ci`，依赖版本固定。
6. Alembic baseline 改为显式 `op.create_table / op.create_index / op.create_foreign_key`，不再使用 `ORM 自动建表`、`列复制方法` 或 `约束复制方法`。
7. 操作审计增强：公司、用户、服务器、Agent 注册、项目接入、项目编辑、执行服务器池、任务调度、告警测试、告警确认/恢复、管理员强制下线等关键写操作写入业务审计。
8. Webhook 通知发送增加 HTTP 状态码检查，非 2xx 视为发送失败。
9. 新增测试覆盖：静态 `sch.py` 解析拒绝动态任务、静态解析成功、Agent 能力配置解析。
10. 新增 `docs/上线测试服务器验收清单.md`，用于测试服务器执行验收。

## 当前环境已执行验证

- Python 编译检查：通过。
- 后端 pytest：13 passed。

- 旧 bootstrap 协议扫描：业务代码和部署模板无旧接口残留，历史文档说明中保留文字记录。
